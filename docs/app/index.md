Выгрузка отчетов осуществляется через вкладку «Отчеты» (рис. 1).

<figure markdown="span">
  ![Рис. 1. Активная вкладка «Отчеты»](/assets/images/fig_1.png)
  <figcaption>Рис. 1. Активная вкладка «Отчеты»</figcaption>
</figure>

Все отчеты сгруппированы по тематическим разделам:

1. **ОПП** — профили добычи/закачки, количество ОПП за год, контуры ФНВ;
2. **Потери** — потери нефти по базе ГТМ ППД, эффект ГТМ ППД по матрице, потери нефти по НФ;
3. **ППД** — пролонгация эффекта ППД по ХВ, выгрузка для компенсаций;
4. **ГДИС** — отчет по ГДИС, пересчет давления на ВНК;
5. **Моделирование** — шаблон для матбаланса (РН-КИН), выгрузка исходников для ММБ (Julia).

По способу получения данных отчеты делятся на:

1. использующие данные из локальной БД;
2. использующие данные из корпоративной базы СМД;
3. не требующие подключения ни к одной из БД.

Форматы дат:

- `ДД.ММ.ГГГГ` - важны день, месяц и год;
- `01.ММ.ГГГГ` - не важен день;
- `01.01.ГГГГ` - не важен день и месяц.
