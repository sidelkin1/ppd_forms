Выгрузка профилей добычи и закачки на последний ненулевой МЭР и последний информативный ОПП за всю историю скважины.

## Параметры для выгрузки
- **Начальная дата** - начало периода для поиска последнего ненулевого МЭР (формат `01.ММ.ГГГГ`);
- **Конечная дата** - конец периода для поиска последнего ненулевого МЭР (формат `01.ММ.ГГГГ`).

## Расшифровка столбцов отчета
- **field** - название месторождения;
- **well_name** - № скважины;
- **cid_all** - список всех объектов разработки;
- **cid** - текущий объект разработки;
- **dat_rep** - дата последнего ненулевого МЭР в интервале **[Начальная дата; Конечная дата]**;
- **liq_rate** - дебит жидкости по МЭР для текущего **cid**, умноженный на **1/num_layer**;
- **inj_rate** - приемистость по МЭР для текущего **cid**, умноженная на **1/num_layer**;
- **liq_rate_all** - суммарный дебит жидкости;
- **inj_rate_all** - суммарная приемистость по МЭР;
- **well_type** - характер работы скважины на момент ОПП;
- **rec_date** - дата последнего за всю историю информативного ОПП;
- **layer** - индекс пласта;
- **diff_absorp** - процент притока/приемистости;
- **remarks** - комментарии интерпретатора ОПП;
- **1/num_layer** - обратная величина от общего количества пластов;
- **liq_rate_layer** - дебит жидкости для данного пласта **layer**;
- **inj_rate_layer** - приемистость для данного пласта **layer**.

## Техническое описание

### Методика выбора последнего ненулевого МЭР

Для каждой комбинации `(месторождение, скважина, объект разработки)` из таблицы `MonthlyReport` отбирается последняя по дате запись в интервале **[Начальная дата; Конечная дата]**, удовлетворяющая условию наличия отбора или закачки:

$$
\text{water} > 0 \quad\text{или}\quad \text{liquid} > 0
$$

Нулевой МЭР (`water = 0` и `liquid = 0`) исключается, поскольку отражает простой скважины в данном месяце. Выбор наиболее поздней даты (`MAX(dat_rep)`) обеспечивает актуальность данных относительно заданного периода.

### Методика выбора последнего информативного ОПП

За всю историю скважины отбирается последний по дате профиль притока (ОПП), для которого суммарный коэффициент притока/приемистости положителен:

$$
\sum_{\forall \text{layer}} \text{diff\_absorp} > 0
$$

Нулевой суммарный коэффициент (`total_absorp = 0`) означает, что ОПП не содержит информативных данных о профиле притока (например, неинтерпретированный или бракованный замер), и исключается из рассмотрения.

Выбор осуществляется трёхэтапно:

1. агрегирование `diff_absorp` по `(скважина, объект, дата)` с суммированием;
2. фильтрация агрегатов с `total_absorp > 0` и взятие последней даты;
3. выборка полного набора полей для записи, соответствующей последней дате.

### Стратегия объединения МЭР и ОПП

Данные МЭР и ОПП связываются через `LEFT OUTER JOIN` по комбинации `(месторождение, скважина, cid_all)`. Это означает, что скважина попадает в отчёт даже при отсутствии профиля ОПП за всю историю — поля, относящиеся к ОПП (`well_type`, `rec_date`, `layer`, `diff_absorp`, `remarks`), принимают в этом случае значение `NULL`.

Важно различать два идентификатора объекта разработки:

- **`cid_all`** — полный список объектов разработки, участвующих в агрегации МЭР (оператор `GROUP BY` по `cid_all`);
- **`cid`** — конкретный объект разработки из строки МЭР.

Строка МЭР относится к одному `cid`, но агрегируется по `cid_all` — общему набору объектов для данной скважины. Аналогично, ОПП привязывается ко всему `cid_all`.

### Методика распределения притока/приемистости по пластам

Поле `layer` в ОПП содержит перечень индексов пластов, разделённых настроечным разделителем (по умолчанию запятая). Каждый индекс пласта преобразуется в отдельную строку — перечень «разбивается» так, чтобы каждая строка соответствовала одному пласту, после чего выполняется равномерное распределение коэффициента притока.

**Равномерное распределение:**

$$
d_i = \frac{D}{n}
$$

где $D$ — исходное значение `diff_absorp` из строки ОПП, $n$ — количество пластов в перечне, $d_i$ — доля притока, приписанная $i$-му пласту.

**Агрегация дубликатов.** После развертки возможно появление нескольких строк с одинаковым набором `(поле, скважина, объект, пласт, ...)`, если исходный перечень содержал повторяющиеся индексы пластов. Такие строки группируются; доли притока суммируются, а комментарии интерпретатора (`remarks`) конкатенируются через запятую с удалением дубликатов.

**Мотивация равномерного распределения.** Исходные данные ОПП не содержат поэлементного разбиения коэффициента притока — `diff_absorp` относится ко всему перечню пластов как к единому целому. В отсутствие дополнительной информации о вкладе каждого пласта равномерное распределение является минимальным предположением, исключающим предвзятость.

### Методика расчета дебита для пласта

Дебит (приемистость) для отдельного пласта вычисляется как доля суммарного дебита, пропорциональная коэффициенту притока:

$$
q_{\text{layer}} = Q_{\text{all}} \cdot \frac{d}{100}
$$

где $Q_{\text{all}}$ — суммарный дебит по всем объектам (`liq_rate_all` или `inj_rate_all`), $d$ — доля притока пласта (`diff_absorp`, %).

**Стратегия обработки пропусков.** При отсутствии профиля ОПП дебит пласта принимается равным скважинному дебиту по МЭР для данного `cid`:

$$
q_{\text{layer}} = q_{\text{well}}
$$

Если ОПП присутствует, но $d = 0$ (пласт без притока), дебит пласта равен нулю — нулевой приток не является пропуском данных.

### Ограничения подхода

- **Равномерное распределение притока.** Предположение о равном вкладе каждого пласта в суммарный коэффициент притока является упрощением. Реальное распределение может быть неравномерным, что приводит к завышению дебита для одних пластов и занижению для других.
- **Независимость МЭР и ОПП по времени.** МЭР и ОПП относятся к разным датам: МЭР — последний в заданном периоде, ОПП — последний за всю историю. Коэффициент притока переносится с даты ОПП на дату МЭР без учёта возможной динамики профиля притока между этими датами.
