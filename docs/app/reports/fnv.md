/// admonition | **Внимание**
    type: warning
При выгрузке ФНВ для всех месторождений время работы может достигать ~20 мин.
///

Выгрузка контуров фронта нагнетаемой воды для загрузки в РН-КИН.

## Параметры для выгрузки
- **Минимальный радиус** - минимальный радиус ФНВ для отрисовки;
- **Выбор месторождения** - выбор одного или всех месторождений для выгрузки ФНВ;
- **Альтернативная БД**:
    - выбрано - построение ФНВ с учетом перфораций НЛД;
    - не выбрано - построение ФНВ согласно только официальной отчетности по перфорациям.

## Формат выходных файлов
- папка с названием месторождения:
    - **fnv.log**: лог с подробной информацией о расчете ФНВ для каждой скважины месторождения;
    - файлы в формате **[Объект]_[Индекс пласта].txt**: контуры ФНВ для загрузки в РН-КИН.
- если при выгрузке по одному из месторождений возникнет непредвиденная ошибка, то в корневой папке появится файл с логом **fnv.log** (при нормальной работе файл будет отсутствовать).

## Техническое описание

### Методика идентификации скважин ППД

Скважины, участвующие в расчёте ФНВ, отбираются по признаку наличия накопленной закачки. Для каждого месторождения из таблицы ежемесячной закачки `MonthlyInj` агрегируется суммарный объём по каждой скважине:

$$
W_{\text{cum}}(\text{uwi}) = \sum_{\text{строки поля}} \text{MonthlyInj.water}
$$

Скважины с нулевой накопленной закачкой ($W_{\text{cum}} = 0$) в выборку не попадают. Расчёт ведётся последовательно по каждой скважине из сформированного списка.

### Методика разрешения объектов разработки

Объекты разработки (пласты) для месторождения извлекаются из таблицы `LayersPty`. В выборку включаются только записи с кодами объекта `numv` равными 1 или 3 — это основные объекты учёта запасов. Для каждого объекта сохраняется идентификатор `cid` и наименование `layer_name`, которые затем используются для группировки контуров.

### Стратегия выбора параметров

**Пористость.** Расчёт опирается на значения пористости из `LayersPty`:

- **Официальная отчётность** (`alternative = false`): используется колонка `porosity` — данные, соответствующие утверждённому подсчёту запасов.
- **НЛД** (`alternative = true`): используется колонка `porosity_alt` — альтернативные оценки, учитывающие нелицензионные дострелы.

Выбор источника пористости задаётся входным параметром **Альтернативная БД** и влияет на все последующие расчёты (профиль притока, закачку, радиус).

**События по скважине.** Аналогично, источник данных о перфорациях и ГДИ зависит от флага `alternative`:

- **Официальная отчётность** (`alternative = false`): перфорации извлекаются из таблицы `Perf`, содержащей утверждённую историю работ.
- **НЛД** (`alternative = true`): перфорации извлекаются из таблицы `PerfAlt`. Типы событий в этой таблице кодируются произвольными текстовыми строками, поэтому выполняется нормализация: действие классифицируется как `SQUEEZE` (заливка), если в нём содержится слово «заливка», и как `PERFORATION` — в противном случае.

Данные ГДИ (`GeophysSt` + `GeophysStAbsorp`) используются из одного источника в обоих режимах. В выборку включаются только записи с ненулевым значением `diff_absorp` (доля притока).

**Перфорация vs ГДИ.** Перфорация (`Perf`/`PerfAlt`) даёт только геометрию интервала (верх, низ), без информации о профиле притока внутри него. ГДИ, напротив, даёт количественный профиль притока (`diff_absorp`), распределённый по интервалу. При совпадении дат предпочтение отдаётся тому типу события, который встретился первым после сортировки (дата по возрастанию, затем `type_action` по убыванию).

### Методика построения профиля притока

Для каждой скважины строится глубинный профиль с шагом 1 см (после перевода глубин в сантиметры). Диапазон профиля — от минимальной кровли до максимальной подошвы среди всех интервалов пористости скважины.

**Заполнение свойств.** Каждой точке профиля присваиваются свойства пласта, в интервал которого она попадает:

- `layer_name`, `cid` — идентификатор объекта разработки;
- `xcoord`, `ycoord` — плановые координаты скважины в пределах данного объекта;
- `poro` — средневзвешенная по эффективной толщине пористость интервала:

$$
\text{poro} = \frac{\sum (h_{\text{eff}} \cdot \varphi)}{\sum h_{\text{eff}}}
$$

- `h_eff` — суммарная эффективная толщина интервала.

где $h_{\text{eff}}$ — мощность пропластка, $\varphi$ — его пористость. Суммирование ведётся по пропласткам с ненулевой эффективной толщиной и ненулевой пористостью в пределах одного интервала (комбинации `layer_name`, `cid` и координат).

**Обработка событий.** События перфорации, заливки и ГДИ сортируются в хронологическом порядке и накладываются на профиль:

- **PERFORATION** — все точки интервала получают значение `1.0` (вскрытая мощность). Предыдущий профиль по перфорациям в этом интервале замещается.
- **SQUEEZE** — все точки интервала получают значение `0.0` (изоляция). Предыдущий профиль по перфорациям в этом интервале замещается.
- **GDI** — значение `diff_absorp` делится поровну между всеми точками интервала притока (равномерное распределение):

$$
\text{share}_i = \frac{\text{diff\_absorp}}{H_{\text{base}} - H_{\text{top}}}
$$

Таким образом, на каждый момент времени (дату события) профиль содержит долю притока для каждой глубинной точки.

**Нормализация.** Для каждой даты суммарная доля притока по всем точкам профиля приводится к единице:

$$
\text{share}_i^{\text{norm}} = \frac{\text{share}_i}{\sum_j \text{share}_j}
$$

Если сумма равна нулю, все доли обнуляются.

### Методика расчёта распределения закачки

Между каждой парой последовательных событий (интервал дат $[t_k, t_{k+1})$) вычисляется суммарный объём закачки $W_{[t_k, t_{k+1})}$:

$$
W_{[t_k, t_{k+1})} = \sum \text{MonthlyInj.water} \quad \text{для} \quad t_k \le \text{dat\_rep} < t_{k+1}
$$

Закачка распределяется по точкам профиля пропорционально нормализованной доле притока на начало интервала:

$$
V_i(t_k) = \text{share}_i^{\text{norm}}(t_k) \cdot W_{[t_k, t_{k+1})}
$$

Суммарная закачка в каждой точке профиля (столбец `total`) — сумма распределённых объёмов по всем временным интервалам:

$$
V_i^{\text{total}} = \sum_{k} V_i(t_k)
$$

### Методика расчёта радиуса ФНВ

Пласт моделируется цилиндром с эффективной толщиной $h_{\text{eff}}$ и пористостью $\varphi$, в который закачан объём $V$, равномерно заполнивший поровое пространство. Радиус фронта воды определяется из баланса:

$$
V = \pi \cdot r^2 \cdot h_{\text{eff}} \cdot \varphi
$$

$$
r = \sqrt{\frac{V}{\pi \cdot h_{\text{eff}} \cdot \varphi}}
$$

Расчёт выполняется агрегированием по объектам разработки (группировка по `layer_name`):

- $V$ — суммарная закачка по всем точкам профиля, относящимся к данному пласту;
- $h_{\text{eff}}$, $\varphi$ — средние значения эффективной толщины и пористости для пласта.

Если знаменатель равен нулю, радиус принимается равным нулю.

### Методика построения контуров

Контур ФНВ для пласта представляет собой окружность с центром в точке плановых координат скважины $(x, y)$ и радиусом $r$. Дискретизация — 50 точек с равномерным угловым шагом:

$$
\begin{aligned}
x_\phi &= r \cdot \cos\left(\frac{2\pi \cdot \phi}{50}\right) + x \\
y_\phi &= r \cdot \sin\left(\frac{2\pi \cdot \phi}{50}\right) + y
\end{aligned}
\quad \phi \in [0, 50)
$$

Контуры строятся только для радиусов, превышающих минимальное пороговое значение **Минимальный радиус** (входной параметр). Контуры с $r \le r_{\min}$ отбрасываются — ФНВ для них считается отсутствующим.

При наличии нескольких скважин в одном пласте контуры объединяются в один файл, где каждый контур отделён маркером `/`.

### Ограничения подхода

- **Цилиндрическая аппроксимация.** Пласт моделируется вертикальным круговым цилиндром, что игнорирует латеральную неоднородность коллектора, геометрию сетки скважин и границы пласта. Фактический фронт вытеснения может существенно отличаться от кругового вследствие анизотропии проницаемости и интерференции скважин.
- **Равномерное распределение закачки.** Предполагается, что закачиваемая вода равномерно распределяется по эффективной толщине пласта. В реальности профиль приёмистости по разрезу может быть резко неоднородным.
- **Отсутствие перетоков.** Модель не учитывает перетоки флюида между пластами и влияние непроницаемых перемычек.
- **ГДИ с одинаковыми кровлей и подошвой.** Если интервал притока в ГДИ имеет нулевую мощность ($H_{\text{top}} = H_{\text{base}}$), подошва искусственно увеличивается на 0.1 см во избежание деления на ноль при распределении доли притока.
- **Конфликт событий на одну дату.** Если перфорация/заливка и ГДИ приходятся на одну дату, обрабатывается только тот тип события, который встретился первым при сортировке (дата по возрастанию, `type_action` — по убыванию). Противоположный тип игнорируется. Приоритет не связан с физикой процесса — это следствие поточного алгоритма обработки.
- **Дискретизация профиля.** Шаг профиля 1 см после перевода в целые числа даёт удовлетворительную точность для типовых мощностей пластов, но может вносить ошибку округления на границах интервалов.
- **Экстраполяция пористости.** Средневзвешенная пористость интервала предполагает однородность свойств по разрезу. Локальные неоднородности (глинистые прослои, кавернозность) не учитываются.

### Стратегия формирования выходных файлов

Для каждого месторождения формируется отдельная подпапка, содержащая:

- **Контуры ФНВ** — файлы вида `[Объект]_[Индекс пласта].txt` в формате РН-КИН. Каждый файл содержит один или несколько контуров, разделённых символом `/`. Контур записывается построчно: координаты $(x, y)$ с точностью до трёх знаков после запятой.
- **Лог расчёта** — файл `fnv.log` с подробной информацией о расчёте для каждой скважины.

Результат упаковывается в ZIP-архив. При возникновении необработанного исключения во время расчёта по отдельному месторождению в корневую папку добавляется `errors.log`, а обработка остальных месторождений продолжается.
