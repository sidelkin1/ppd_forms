Сводная таблица для карт изобар: фонд скважин с предыдущими и текущими замерами пластового давления, объединённый в одну книгу для построения карт изобар.

## Параметры для выгрузки

- **Файл предыдущей сводной** — файл предыдущей карты изобар `СВОДНЫЙ_ИЗОБАРЫ_ДД.ММ.ГГГГ.xlsm` с листом «текущие отборы». Дата в имени файла должна быть первым числом месяца (например `СВОДНЫЙ_ИЗОБАРЫ_01.07.2026.xlsm`). Из файла читаются столбцы: месторождение, объект работы, номер скважины, пластовое давление, дата исследования, вид исследования. Названия месторождения, объекта и скважины (с учётом ствола `B1`, `B2` и т.п.) нормализуются через справочники замены.

Из даты файла выводятся расчётные даты:

- `previous_date` — дата предыдущей карты (из имени файла);
- `on_date = previous_date + 3 месяца` — дата новой карты;
- `stock_date = on_date − 1 месяц` — дата фонда.

## Формат выходных файлов

Выгружается копия загруженного шаблона с именем `СВОДНЫЙ_ИЗОБАРЫ_<on_date>.<ext>`, где `<ext>` — расширение загруженного шаблона. Строки шаблона заполняются данными по колонкам:

- **C–G** — месторождение, объект работы, скважина, характер работы, состояние;
- **H** — пластовое давление (формула шаблона);
- **I** — забойное давление из техрежима;
- **J–N** — предыдущий замер: пластовое давление, дата, вид исследования, характер работы, состояние;
- **O–Q** — текущий квартальный замер: пластовое давление, дата, вид исследования;
- **AC–AE** — неуспешный замер: пластовое давление, дата, вид исследования;
- **AH** — давление насыщения.

При расхождениях дополнительно формируются диагностические CSV (упаковываются в тот же ZIP):

- `…_нет_строки_в_сводной.csv` — скважины фонда без строки в предыдущей сводной;
- `…_нет_данных_гдис.csv` — строки предыдущей сводной, которым не нашлось пары в замерах ГДИС;
- `…_нет_в_фонде_сводная.csv` — строки предыдущей сводной с Рпл, которым нет пары в фонде;
- `…_нет_в_фонде_welltest.csv` — текущие замеры welltest, которым нет пары в фонде;
- `…_ствол_не_определен.csv` — замеры, для которых не удалось определить ствол.

## Техническое описание

### Источники данных

Отчёт собирает данные из трёх источников:

1. **Фонд, PVT и техрежим (OFM/Oracle).** Текущий фонд дополняется прежними стволами тех же объектов и стволами с открытой перфорацией, которых нет в фонде. Из `ResPty` берутся начальное пластовое давление и давление насыщения, из таблиц техрежима — пластовое и забойное давление.
2. **Замеры ГДИС (локальная БД).** Последние успешные и неуспешные замеры по каждой скважине на дату отчёта.
3. **Предыдущая сводная (загруженный файл).** Предыдущие значения пластового давления, даты и вида исследования.

### Разрешение ствола по перфорации

Скважина может быть представлена несколькими стволами (`W2`, `W2B1`, …). Текущий замер привязывается к стволу, у которого на дату замера была открыта перфорация в целевом объекте. Если такого ствола нет, замер остаётся на родительском стволе.

### Синтетические состояния

Стволам, которых нет в справочнике состояний, присваиваются синтетические состояния, выделенные в отчёте скобками и курсивом:

- `стар. ствол` — прежний ствол объекта;
- `открыт. перф.` — ствол с открытой перфорацией, отсутствующий в фонде.

### Ограничения подхода

- Склейка с техрежимом выполняется только для текущих стволов: у прежних стволов и стволов с открытой перфорацией давления техрежима не заполняются.
- Объект работы резолвится к базовому идентификатору (`mr` → `id`), чтобы смена объекта на ИЖВ и обратно не давала лишних прежних стволов.
