Расчет изменений дебита нефти по факторам (жидкость и обводненность) по добывающему окружению нагнетательных скважин согласно списку из базы ГТМ ППД: `U:/Documents/ИНТЦ/База ГТМ`.

## Параметры для выгрузки
- **Начальная дата** - начало периода расчета по МЭР (формат `01.ММ.ГГГГ`);
- **Конечная дата** - конец периода расчета по МЭР (формат `01.ММ.ГГГГ`);
- **Режим выгрузки**:
    - **Qн на начало периода**: при расчете потерь Qн в качестве стартовой точки берется первый ненулевой Qн по МЭР в интервале **[Начальная дата; Конечная дата]**;
    - **Максимальный Qн**: при расчете потерь Qн в качестве стартовой точки берется максимальный Qн по МЭР в интервале **[Начальная дата; Конечная дата]**;
    - Конечная точка во всех режимах соответствует Qн на дату **Конечная дата**; если МЭР отсутствует на эту дату, то условно считается, что Qн равен 0 т/сут.
- **Округа из НС ППД**:
    - **выбрано** - приоритет отдается округе из таблицы **НС ППД** (для последнего ГТМ по скважине); если ее нет или она пустая, то окружение берется из таблицы **Округа** в локальной БД;
    - **не выбрано** - округа берется только из таблицы **Округа** в локальной БД.

## Техническое описание

### Методика формирования списка нагнетательных скважин

Список нагнетательных скважин берётся из таблицы **База ГТМ ППД** (`InjWellDatabase`). Для каждой скважины определяется актуальный объект разработки на момент последней ненулевой закачки по **МЭР** (запись с максимальной датой среди строк, где `water > 0` или `liquid > 0`). Используется поле `cid_all` — оно может содержать несколько идентификаторов объектов, закреплённых за скважиной на эту дату.

### Методика разрешения объектов разработки

Одна скважина может быть привязана к нескольким объектам разработки одновременно. Поле `cid_all` хранит перечень идентификаторов, разделённых разделителем (например, `","`). Для корректного анализа каждый объект рассматривается независимо:

- Исходная строка с `cid_all` разбивается по разделителю → для каждого объекта создаётся отдельная строка с копией всех параметров скважины.
- Исходное значение `cid_all` сохраняется в столбце `reservoir_all` как справочная информация.

### Стратегия выбора параметров МЭР

Расчёт потерь нефти — сравнение двух временных срезов: стартовой точки и конечной. Конечная точка всегда соответствует дате **Конечная дата** (`date_to`). Выбор стартовой точки зависит от режима выгрузки:

**Режим «Qн на начало периода» (first rate).** Стартовой точкой считается первая ненулевая запись МЭР в интервале `[date_from, date_to]`. Для нагнетательных скважин поиск ведётся по приёмистости (`inj_rate > 0`); для добывающего окружения — по дебиту жидкости (`liq_rate > 0`). Берётся минимальная дата среди удовлетворяющих условию записей.

**Режим «Максимальный Qн» (max rate).** Стартовой точкой считается дата максимального значения в интервале `[date_from, date_to]`. Для нагнетательных скважин используется максимальная приёмистость; для добывающего окружения — максимальный дебит нефти. Максимум считается независимо в каждом разрезе «скважина–объект», а не агрегированно по скважине.

**Конечная точка.** Для нагнетательных — запись на дату `date_to` с ненулевой закачкой. Для добывающих — запись на дату `date_to` с ненулевой жидкостью. Если МЭР на дату `date_to` отсутствует, соответствующие дебиты (`oil_rate`, `liq_rate`, `inj_rate`) принимаются равными нулю.

### Методика формирования окружения

Окружение нагнетательной скважины — перечень добывающих скважин, на которые предположительно влияет изменение режима закачки. Формируется из двух источников с настраиваемым приоритетом:

- **НС ППД** (`NewStrategyInj`) — округа, определённая для последнего ГТМ ППД по данной скважине (максимальная `gtm_date`, где `neighbs IS NOT NULL`);
- **Округа** (`Neighborhood`) — актуальное окружение из справочника.

При установке флага **Округа из НС ППД** (`neighbs_from_ns_ppd = True`) приоритет отдаётся данным НС ППД; при их отсутствии (`NULL` или пустая строка) — заполнению из справочника **Округа**. При снятом флаге используется только справочник **Округа**.

Окружение (`neighbs`) может содержать несколько номеров скважин, разделённых разделителем — аналогично объектам, каждая скважина окружения разворачивается в отдельную строку.

### Методика факторного анализа потерь нефти

Расчеты проводятся согласно ЛНД ЗАО Компании П1-01.03 И-0033 [«Мониторинг и оперативный факторный анализ изменений дебитов добывающих скважин»](/assets/references/BP1-01-03_TTR-0033_IZM1.docx).

Оценка изменения дебита нефти добывающего окружения выполняется методом декомпозиции на две составляющие: влияние дебита жидкости и влияние обводнённости. Для каждой пары «нагнетательная скважина–соседняя добывающая» в разрезе объекта разработки вычисляются:

**Нефтяная обводнённость (oilcut)** на стартовую и конечную даты:

$$
W_{\text{oil}}^{\text{start}} = \frac{Q_{\text{oil}}^{\text{start}}}{Q_{\text{liq}}^{\text{start}}},
\quad
W_{\text{oil}}^{\text{end}} = \frac{Q_{\text{oil}}^{\text{end}}}{Q_{\text{liq}}^{\text{end}}}
$$

При отсутствии данных на одном из срезов обводнённость заполняется значением с другого среза; при отсутствии обоих — нулём. Если $Q_{\text{liq}} = 0$, то $W_{\text{oil}} = 0$.

**Изменение приёмистости нагнетательной скважины:**

$$
\Delta W = Q_{\text{inj}}^{\text{end}} - Q_{\text{inj}}^{\text{start}}
$$

**Факторный анализ изменения дебита нефти добывающей скважины:**

Общее изменение:

$$
\Delta Q_{\text{oil}} = Q_{\text{oil}}^{\text{end}} - Q_{\text{oil}}^{\text{start}}
$$

Декомпозиция по факторам:

$$
\Delta Q_{\text{oil}} = \underbrace{\frac{W_{\text{oil}}^{\text{start}} + W_{\text{oil}}^{\text{end}}}{2} \cdot \left(Q_{\text{liq}}^{\text{end}} - Q_{\text{liq}}^{\text{start}}\right)}_{\Delta Q_{\text{oil}}(\Delta Q_{\text{liq}})} \;+\; \underbrace{\frac{Q_{\text{liq}}^{\text{start}} + Q_{\text{liq}}^{\text{end}}}{2} \cdot \left(W_{\text{oil}}^{\text{end}} - W_{\text{oil}}^{\text{start}}\right)}_{\Delta Q_{\text{oil}}(\Delta W_{\text{cut}})}
$$

где:

- $\Delta Q_{\text{oil}}(\Delta Q_{\text{liq}})$ — вклад изменения дебита жидкости, взвешенный на среднюю обводнённость;
- $\Delta Q_{\text{oil}}(\Delta W_{\text{cut}})$ — вклад изменения обводнённости, взвешенный на средний дебит жидкости.

**Агрегация по окружению.** Потери агрегируются в разрезе «месторождение–нагнетательная скважина–соседняя добывающая скважина» суммированием $\Delta Q_{\text{oil}}$, $\Delta Q_{\text{oil}}(\Delta Q_{\text{liq}})$ и $\Delta Q_{\text{oil}}(\Delta W_{\text{cut}})$ по всем объектам разработки. Результат форматируется в строку вида `скважина (значение)`; для каждой нагнетательной скважины строки по соседям конкатенируются через запятую в итоговые столбцы `neighbs_loss_all`, `neighbs_loss_liq`, `neighbs_loss_wcut`.

### Ограничения подхода

- **Временная дискретность.** Анализ использует два моментальных среза, игнорируя динамику показателей внутри интервала. Промежуточные изменения закачки/отборов не учитываются.

- **Причинно-следственная связь.** Отчёт фиксирует корреляцию изменений, но не устанавливает причинность: снижение дебита нефти соседней добывающей скважины может быть вызвано факторами, не связанными с изменением закачки (ремонт, смена насоса, прорыв газа и т.д.).

- **Пропуски в МЭР.** При отсутствии записи МЭР на конечную дату все дебиты принимаются равными нулю, что завышает величину потерь. Для стартовой точки отсутствие записи с ненулевым дебитом приводит к исключению скважины из анализа по данному объекту.

- **Полнота окружения.** Если НС ППД и справочник **Округа** одновременно не содержат данных по окружению скважины (`neighbs = NULL` или пустая строка), соседние добывающие скважины не будут идентифицированы — скважина останется в отчёте, но без расчёта потерь.

- **Инклинометрия и давления.** Отчёт не учитывает изменение забойного/пластового давления, неравномерность фронта вытеснения и геологическую неоднородность пласта.
