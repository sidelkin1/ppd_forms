Пересчет давления на глубину с учетом инклинометрии скважины.

## Параметры для выгрузки
- **Выбор месторождения** - выбор месторождения для расчета;
- **Выбор объекта** - выбор объекта для расчета;
- **Номер скважины** – номер скважины для расчета;
- **Давление (атм)** - давление на глубине для пересчета;
- **Глубина (м)** - глубина замера давления;
- **Выбор вида исследования** - вид исследования для заполнения аналитики;
- **На дату** - дата замера давления.

## Формат выходных файлов
- **owc_resp_template.xlsx** - калькулятор для пересчета замеренного давления на глубины ВНК и ВДП:
    * **лист "Пересчет"** - основной лист для расчета;
    * **лист "Глубины"** - инклинометрия скважины;
- **analytics_template.xlsx** - формат аналитики для загрузки в РН-КИН:
    * заполняются только столбцы выделенные желтым цветом.

## Техническое описание

### Методика идентификации ствола скважины

Скважина в СМД может быть представлена несколькими записями: родительский ствол и боковые ответвления. Выбор релевантного ствола для расчёта давления основан на следующей стратегии:

1. **Поиск ствола с открытой перфорацией на дату замера.** Если на дату (входной параметр **На дату**) существует боковой ствол, у которого открыт интервал перфорации в целевом объекте — используется он, так как замер давления физически относится к работающему интервалу.
2. **Откат на родительский ствол.** Если боковых стволов с открытой перфорацией нет — расчёт ведётся по родительскому стволу.

Выбор первого подходящего ствола (функция `MIN(uwi)`) означает, что при нескольких боковых стволах с открытой перфорацией (скважина МЗС) предпочтение отдаётся стволу с лексикографически меньшим идентификатором — фактически произвольный выбор, который может не соответствовать фактическому интервалу замера.

### Методика разрешения объекта разработки

Один и тот же объект разработки (пласт) может быть закодирован разными идентификаторами для учета номера лицензии. Словарь `DictG` содержит кросс-ссылки между основным идентификатором и его синонимами. Стратегия поиска данных по объекту — применение SQL-оператора `UNION` для прямого идентификатора и всех его псевдонимов, чтобы не пропустить записи, привязанные к синонимам.

### Стратегия выбора параметров

**Плотность воды.** Приоритет отдаётся фактическим замерам из `WellMonthHistPty` (последняя запись до даты замера) над справочным значением ГФХ из `ResPty`. Мотивация: минерализация и плотность пластовой воды меняются в процессе разработки.

**Обводнённость.** Для нефтяных скважин рассчитывается по последнему доступному МЭР. Предполагается, что обводнённость относительно стабильна между замерами. Граничные случаи:

- Нет данных МЭР (`NULL`) → обводнённость принимается равной 100%.
- Суммарный объемный дебит жидкости равен нулю → также 100%.

Последнее имеет место для всех скважин, кроме нефтяных — нагнетательных, поглощающих и т.д.

**Состояние скважины.** Используется последнее известное состояние на дату ≤ входного параметра **На дату**.

### Методика учёта инклинометрии

Для пересчёта давления по вертикали необходимо знать вертикальную глубину (TVD) каждой точки. Поправка на отклонение ствола от вертикали — **удлинение** $\Delta(H) = \text{MD} - \text{TVD}$.

Используется **линейная интерполяция** удлинения между точками инклинометрии:

$$
\Delta(H) = \text{interp}\big(H,\; \{ \text{md}_i \},\; \{ \text{md}_i - \text{tvd}_i \}\big)
$$

где $\{ \text{md}_i \}$ и $\{ \text{md}_i - \text{tvd}_i \}$ — массивы измеренных глубин и соответствующих поправок из `WellDirSrvyPts`, отсортированные по возрастанию MD.
При выходе $H$ за границы массива используется экстраполяция по ближайшему значению.

### Ограничения подхода

- Линейная интерполяция не учитывает кривизну ствола между точками съёмки — даёт приближённый результат, погрешность которого зависит от густоты точек замера.
- При полном отсутствии данных инклинометрии $\Delta(H)$ принимает значение `NaN`, что распространяется на все расчётные давления.

### Методика пересчёта давлений

Задача: привести замеренное на глубине $H_{\text{зам}}$ (MD) давление $P_{\text{зам}}$ к двум целевым глубинам — верхним дырам перфорации $H_{\text{вдп}}$ и водонефтяному контакту $H_{\text{внк}}^{\text{абс}}$.

**Плотность жидкости** — средневзвешенная по обводнённости:

$$
\rho_{\text{liq}} = \rho_{\text{oil}} \cdot \left(1 - \frac{W}{100}\right) + \rho_{\text{water}} \cdot \frac{W}{100}
$$

где $\rho_{\text{oil}}$ и $\rho_{\text{water}}$ — плотности нефти и воды (г/см³), $W$ — обводнённость (%). Расчёт предполагает однородную по стволу жидкость; градиенты температуры и давления не учитываются.

**Давление на верхних дырах перфорации (ВДП):**

$$
P_{\text{вдп}} = P_{\text{зам}} + \frac{\rho_{\text{liq}}}{10} \cdot \Big[ \big(H_{\text{вдп}} - \Delta(H_{\text{вдп}})\big) - \big(H_{\text{зам}} - \Delta(H_{\text{зам}})\big) \Big]
$$

Разность в квадратных скобках — расстояние по вертикали между глубиной замера и ВДП. Положительная разность означает, что ВДП находятся ниже точки замера (давление увеличивается за счёт столба жидкости).

**Давление на ВНК:**

$$
P_{\text{внк}} = P_{\text{зам}} + \frac{\rho_{\text{liq}}}{10} \cdot \Big[ H_{\text{внк}}^{\text{абс}} - \big(H_{\text{зам}} - \Delta(H_{\text{зам}}) - H_{\text{альт}}\big) \Big]
$$

где $H_{\text{альт}}$ — альтитуда устья (м). Выражение $(H_{\text{зам}} - \Delta(H_{\text{зам}}) - H_{\text{альт}})$ даёт абсолютную вертикальную глубину точки замера (TVD минус превышение устья над уровнем моря). Разность с $H_{\text{внк}}^{\text{абс}}$ — расстояние по вертикали до ВНК в абсолютных отметках.

### Стратегия формирования выходных файлов

Формируются два Excel-файла, которые затем упаковываются в ZIP-архив:

**Калькулятор** (`owc_resp_template.xlsx`) — инженерный инструмент для ручной верификации. В шаблон подставляются только исходные данные в фиксированные ячейки (B1–B15 листа «Пересчет»); формулы пересчёта давлений находятся в самом шаблоне и используют эти ячейки как входные параметры. Такой подход позволяет инженеру изменить любой параметр и немедленно увидеть результат пересчёта средствами Excel. Лист «Глубины» заполняется полной таблицей инклинометрии (MD, TVD, удлинение).

**Аналитика** (`analytics_template.xlsx`) — формат для загрузки в РН-КИН. Заполняются только столбцы, выделенные в шаблоне жёлтым цветом; остальные столбцы либо вычисляются формулами Excel, либо заполняются вручную на стороне РН-КИН. Состав заполняемых полей
зависит от вида исследования:

- **Hст** (статический уровень): измеренная глубина интерпретируется как глубина статического уровня, измеренное давление — как затрубное.
- **Pпл** (прямой замер): измеренные глубина и давление записываются как есть.
